Votre première connexion, étape par étape

  1. Ouvrez {{ site_nom }} et cliquez sur Se connecter.
  2. Saisissez votre {{ identifiant_nom }} et le mot de passe temporaire ci-dessus (le plus sûr est de le copier-coller).
  3. La page Nouveau mot de passe s'affiche : choisissez votre propre mot de passe (8 caractères minimum, en mélangeant majuscules, minuscules, chiffres et symbole), puis confirmez-le. Le mot de passe temporaire ne fonctionnera plus.
  4. Installez Google Authenticator sur votre téléphone (gratuit, éditeur Google LLC, sur Play Store ou App Store). Appuyez sur +, puis Scanner un code QR, et visez le QR code affiché par PERED. Si vous êtes sur votre téléphone, choisissez plutôt Saisir une clé de configuration et copiez la clé affichée sous le QR code.
  5. Saisissez le code à 6 chiffres affiché dans l'application : votre session s'ouvre.

Les fois suivantes : votre {{ identifiant_nom }}, votre nouveau mot de passe et le code à 6 chiffres de Google Authenticator.
